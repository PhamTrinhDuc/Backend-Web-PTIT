Giả sử bạn vào quán cà phê, gọi một ly cà phê sữa. Quá trình này diễn ra như sau:
    Bạn gọi món với nhân viên thu ngân.
    Thu ngân gửi yêu cầu đến nhân viên pha chế.
    Nhân viên pha chế kiểm tra nguyên liệu trong kho.
    Nếu có nguyên liệu, pha chế xong sẽ đưa cho bạn.

Trong hệ thống Spring Boot, mỗi thành phần đóng vai trò tương ứng:
    Controller 🏢 = Nhân viên thu ngân.
    Service ☕ = Nhân viên pha chế.
    Repository 📦 = Kho nguyên liệu (CSDL).
    Model (Entity) 📜 = Công thức pha chế.
    DTO 🎁 = Cốc cà phê mang ra cho khách.

Luồng hoạt động:
    📌 Khách hàng (client) gửi yêu cầu HTTP POST, Controller nhận và gọi Service.
    📌 Service xử lý logic chính: Kiểm tra nguyên liệu, gọi Repository để lấy dữ liệu.
    📌 Repository tương tác với Database, lấy dữ liệu hoặc lưu đơn hàng mới.
    📌 Repository tương tác với Database, lấy dữ liệu hoặc lưu đơn hàng mới.
    📌 DTO giúp ẩn bớt dữ liệu không cần thiết, chỉ trả về thông tin cần thiết cho client.

* JPA (Java Persistence API) là một chuẩn giúp bạn làm việc với database bằng Java một cách dễ dàng hơn, thay vì phải viết SQL thủ công.

* Hibernate là một ORM (Object-Relational Mapping) Framework giúp bạn tương tác với cơ sở dữ liệu (CSDL) bằng Java mà không cần viết câu lệnh SQL thuần.
📌 Nói đơn giản, Hibernate giúp làm gì?
Chuyển đổi đối tượng Java (Object) ↔ Bảng trong CSDL (Row)
Tự động tạo bảng, truy vấn, insert, update, delete dữ liệu mà không cần viết SQL thủ công.
Hỗ trợ caching, transaction, lazy loading, giúp tối ưu hiệu suất.

- Hibernate hỗ trợ nhiều cách để tự thiết kế câu query tùy theo nhu cầu
JPQL (@Query)	Ngắn gọn, dễ dùng	Không hỗ trợ SQL thuần
Native Query (SQL gốc)	Mạnh mẽ, tối ưu hiệu suất	Không tận dụng được sức mạnh ORM
Criteria API	Linh hoạt, không cần viết SQL thủ công	Cú pháp dài dòng
HQL	Hỗ trợ hướng đối tượng	Cần học cú pháp riêng

* Spring Data JPA không phải là một ORM, mà chỉ là một lớp abstraction (tầng trừu tượng) giúp làm việc với JPA (Java Persistence API) dễ dàng hơn. Còn Hibernate là một ORM cụ thể được Spring Data JPA sử dụng mặc định.
📌 Nếu dùng Spring Data JPA với Hibernate: Bạn đang dùng Hibernate làm ORM để thao tác với CSDL thông qua JPA.
📌 Nếu không có Hibernate: Bạn có thể thay Hibernate bằng một ORM khác hoặc tự viết JDBC để làm việc với CSDL.

* Quan hệ nhiều dữ liệu (OneToMany, ManyToMany) → FetchType.LAZY ✅ => dữ liệu liên kết sẽ chỉ được tải khi thực sự cần thiết.
Quan hệ đơn giản, ít dữ liệu (OneToOne, ManyToOne) → có thể để EAGER nhưng nên test hiệu suất 🚀 => muốn luôn tải dữ liệu liên quan ngay lập tức, dùng EAGER.


* CascadeType	    Mô tả
ALL	            Áp dụng tất cả các loại cascade.
PERSIST	        Khi lưu entity cha, entity con cũng được lưu.
MERGE	        Khi cập nhật entity cha, entity con cũng được cập nhật.
REMOVE	        Khi xóa entity cha, entity con cũng bị xóa.
REFRESH	        Khi làm mới entity cha, entity con cũng được làm mới từ database.
DETACH	        Khi tách entity cha khỏi Persistence Context, entity con cũng bị tách.


* @Transactional được dùng để quản lý giao dịch (transaction) trong Spring. Nó đảm bảo rằng nếu một đoạn code thực hiện nhiều thao tác (SELECT, INSERT, UPDATE, DELETE) trên database thì:

Thành công → Commit dữ liệu vào DB.
Thất bại (lỗi, exception) → Rollback (hủy bỏ tất cả thay đổi).
